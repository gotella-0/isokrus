# История экспериментов: от «перечисли ветви» к «отметь вложенное»

Семнадцать версий промта и схемы ответа (`research/exp_01` … `exp_17`),
десять моделей, 74 прогона. Здесь — линия решений с результатами; полный
отчёт с обоснованием каждого числа: [research/ИСТОРИЯ_ИССЛЕДОВАНИЙ.md](../research/ИСТОРИЯ_ИССЛЕДОВАНИЙ.md).

## Эволюция формы ответа

| Версия | Идея | Результат |
|---|---|---|
| `exp_01` | модель пишет размеры и bbox, сумма по «вошло/не вошло» | модель промахивается чтением: «22100» вместо `24100` |
| `exp_02` | плоский список чисел без bbox | точность exp_01, но без разметки |
| `exp_03` | трактовка через маршрут: границы, обход с самопроверкой суммы | хуже exp_01/exp_02 |
| `exp_04` | иерархия: обобщённые ветви + вложенные участки | 3/10: модель склеивает `900 + 200` в «1100» |
| `exp_05` | **выбор по меткам**: модель не пишет числа, сумма — программа | перелом: ошибка чтения исключена по построению |
| `exp_06`…`exp_12` | правила вложенности: ось, перекрытие, зазоры | 7–9/10; усиление одного правила ослабляло противоположное |
| `exp_13` | короткий промт: проекционный интервал, правило по умолчанию, «величина не основание» | **10/10, Σ\|Δ\| = 0** (дважды подряд) |
| `exp_14`…`exp_17` | попытки улучшить exp_13 (оси словами, цепочки правил, асимметрия) | не превзошли: длиннее промт — тот же результат |

Три правила промта `exp_13`, которые всё решают:

1. **Проекционный интервал.** Размер вложен, если его отрезок целиком или
   частично внутри интервала более длинного размера на той же ветке.
2. **Правило по умолчанию.** Размеры «конец в конец» вдоль одной линии —
   смежные звенья, все входят.
3. **Величина не является основанием для исключения.** Размер между двумя
   точками трассы — длина участка, каким бы малым ни было число. Геометрическое
   дублирование — единственное основание.

## Что не сработало

* **Метки на листе** (`--labels`, плашки `P7` у чисел) — в 5 из 6 проверок
  *ухудшили* результат: подсказка на листе мешает модели проверить геометрию.
* **Ось словами** (`exp_15`) — правило «вложенный только вдоль той же оси»
  на словах не работало: модель подбирала правдоподобные ложные основания.
  Сработала передача оси **данными** в блоке `{{DIMENSIONS}}`.
* **Большие промты** (`exp_16`, `exp_17` — 11–12 тыс. символов против 9 тыс.)
  — купили ровно ничего при том же результате.
* **Подсветка размерных линий** (`--overlay`) — точность ниже по замерам;
  отключена по умолчанию.

## Решающая правка оказалась не в промте

Остаток `+190` на листе 4 не закрывался десятью промтами подряд. Виноват был
разбор: засечка у наконечника (22,8 пт, перпендикулярно линии) проходила
порогом касания и забирала число `190` у настоящей размерной линии. Замер
по всем 114 размерам книги показал: кончик наконечника рисуется ровно в конце
линии, зазор — ноль. Порог `arrow_gap` 1,0 → 0,2 пт — и 9/10 стало 10/10 без
изменения ни одного другого листа. Урок: **вход был одинаковый, поэтому
и ответы моделей были одинаково неверные** — прежде чем править промт,
проверь данные.
