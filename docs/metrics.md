# Показатели работы

По требованиям задания: используемые модели, время обработки, среднее число
обращений к ИИ на страницу и стоимость страницы.

## Финальный прогон (эксперимент `exp_13`)

| Показатель | Значение |
|---|---|
| Модель | `gpt-6-luna` |
| Режим рассуждения | `high` |
| Листов обработано | 10 из 10, ошибок нет |
| Общее время | 98,4 с |
| Время на страницу | 9,8 с (прогон при параллельности 10) |
| Обращений к ИИ на страницу | **1,0** (ретраев: 0) |
| Токены на страницу (среднее) | 5 579 prompt, 3 062 reasoning, 115 output |

| Стоимость всего прогона | 1,64 руб. |
| Результат | **10/10 листов точно, Σ\|Δ\| = 0 мм** |

## Как считалась стоимость

Тариф `gpt-6-luna` — 10 / 50 / 50 руб за 1M токенов (input / output /
reasoning), запись в кеш 12,5, чтение из кеша 1,0. Стоимость разложена по
факту использования API, из `stats.json` прогона:

| Компонент | Токены (всего) | Расчёт | Стоимость |
|---|---|---|---|
| Рассуждение | 30 618 | 0,0306 M × 50 | 1,5309 руб. |
| Ответ (visible output) | 1 147 | 0,0011 M × 50 | 0,0573 руб. |
| Кеш: чтение | 55 761 | 0,0558 M × 1,0 | 0,0558 руб. |
| Кеш: запись | 0 | — | 0,0 |
| Вход (prompt минус кеш) | 30 | 0,00003 M × 10 | 0,0003 руб. |
| **Итого** | | | **1,6443 руб. / 10 листов** |

Особенность учёта: `prompt_tokens` у провайдера **включает** и запись в кеш,
и чтение из него (проверено запросом: 2358 = 2355 кеш + 3 служебных). Поэтому
обычный вход считается как `prompt минус кеш` — иначе кеш оплачивался бы
дважды. Токены рассуждения входят в `completion_tokens`, но тарифицируются
отдельно: обычный output считается как `completion минус reasoning`. Разложение
видно в `stats.json` каждого прогона: `cache_write_tokens`,
`cache_read_tokens`, `cost_*`.

## Сравнение моделей по стоимости листа

| Модель | Режим | Точно | Руб/лист |
|---|---|---|---|
| `gpt-6-luna` | high | **10/10** | 0,263 (группа прогонов), 0,164 (финальный) |
| `gpt-6-luna` | medium | 9/10 | 0,234 |
| `gpt-6-luna` | low | 7/10 | 0,107 |
| `glm-5.3-flash` | low | 5/10 | 0,037 |
| `qwen3.7-plus` | medium | 2/10 | 0,664 |

Обоснование выбора: `glm-5.3-flash` в 7 раз дешевле, но вчетверо хуже по
лучшему результату; `qwen3.7-plus` дороже и вдвое хуже; `high` против
`medium` — единственная пара, где доплата даёт лист из десяти. Детальный
разбор всех моделей и 74 прогонов: [experiments.md](experiments.md).

## Воспроизведение

Стоимость и статистика пишутся каждым прогоном автоматически:

```bash
# тарифы модели задаются в .env через LLM_PRICING_TABLE
python -m isokrus run "02_Изометрии_10_листов.pdf" --experiment exp_13 \
  --model gpt-6-luna --reasoning high

# после прогона:
#   output/exp_13_*/stats.json  — время, токены, стоимость, ретраи
#   output/exp_13_*/result.csv  — таблица по листам (задание, п.4)
```

Все прогонные данные этой документации лежат в `output/exp_13_*/stats.json`.
